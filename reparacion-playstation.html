Antes de empezar

El objetivo no es adivinar qué pieza está dañada. Primero se reproduce el síntoma, se hacen pruebas sencillas y se elimina cada posible causa. Si una prueba cambia el comportamiento, documenta el resultado y úsalo para el siguiente paso.

Procedimiento paso a paso

  1. Paso 1: Identifica si el problema es encendido, vídeo, temperatura, almacenamiento o software.
  2. Paso 2: Para vídeo, prueba otro HDMI, entrada y pantalla.
  3. Paso 3: Para apagados, verifica ventilación y si ocurre después de varios minutos.
  4. Paso 4: Para errores de almacenamiento, realiza primero las comprobaciones de software disponibles.
  5. Paso 5: Si no hay respuesta de encendido, mide la alimentación solo con experiencia técnica.
  6. Paso 6: Documenta el diagnóstico y evita cambiar chips sin evidencia.

Precauciones

La reparación de placa requiere instrumental y experiencia. No recomendamos puentes ni inyecciones de voltaje sin conocer el circuito.

Cómo documentar el diagnóstico

Anota modelo exacto, síntoma, pruebas realizadas y resultado de cada prueba. Si publicas el caso en Facebook, añade fotografías del equipo antes y después, pero elimina datos personales que aparezcan en pantalla.
