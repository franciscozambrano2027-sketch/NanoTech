PC: SSD no detectado o Windows no arranca

Introducción

Objetivo

Separa detección en BIOS, conexión física, salud del almacenamiento y problemas de arranque de Windows. La guía busca que puedas separar causas antes de sustituir componentes.

Antes de empezar: seguridad

⚠ Precaución

Desconecta el equipo cuando corresponda y no realices mediciones peligrosas sin formación e instrumental. En baterías, fuentes y placas, detén el procedimiento si detectas daño físico, líquido, olor extraño o calor anormal.

  • Documenta el estado inicial.
  • Haz una sola modificación cada vez.
  • Conserva tornillos, cables y configuración original.

Herramientas

BIOS/UEFIMedio de recuperaciónSoftware SMARTCable SATA/M.2
01

1. Comprobar BIOS/UEFI

Primero determina si el firmware detecta el almacenamiento.

Qué hacer

  1. Entra al firmware (Supr, F2 o F10 según el fabricante) antes de que cargue el sistema.
  2. Busca la sección de almacenamiento y verifica si el SSD aparece listado con su nombre de modelo.
  3. Anota modelo y capacidad: una capacidad muy inferior a la nominal (por ejemplo unos pocos MB en vez de 500GB) es típico de un controlador de SSD fallado.
Punto de control

Primero determina si el firmware detecta el almacenamiento: si el BIOS ni siquiera ve el disco, reparar Windows o el sistema de archivos es inútil hasta resolver esto.

Interpretación

Primero determina si el firmware detecta el almacenamiento.

02

2. Revisar conexión

Un problema de cable o montaje puede parecer un SSD muerto.

Qué hacer

  1. En SATA, con el equipo desconectado, revisa que datos y alimentación estén bien encajados en ambos extremos; prueba también otro cable SATA.
  2. En M.2, verifica que el módulo esté insertado a fondo (ángulo de 30° antes de atornillar) y el tornillo de retención puesto.
  3. Confirma que el slot M.2 soporte el tipo de tu SSD (SATA o NVMe): algunos slots solo aceptan uno de los dos.
  4. Prueba otro puerto SATA o slot M.2 para descartar el puerto específico.
Punto de control

Un problema de cable o montaje puede parecer un SSD muerto: agotar las variables de conexión es más rápido y barato que asumir una falla del disco.

Interpretación

Un problema de cable o montaje puede parecer un SSD muerto.

03

3. Separar hardware de Windows

Si BIOS detecta el disco, el problema puede ser de arranque o sistema.

Qué hacer

  1. Crea un USB de instalación de Windows en otro equipo si no tienes uno a mano.
  2. Arranca desde el USB y usa "Reparar el equipo" > "Opciones avanzadas" > "Reparación de inicio" antes de considerar reinstalar.
  3. No formatees ni reinstales como primer paso si necesitas conservar datos: la reparación de inicio no borra archivos, una reinstalación sí.
Punto de control

Si BIOS detecta el disco, el problema puede ser de arranque o sistema, no del hardware: forzar una reinstalación cuando solo era el sector de arranque dañado pierde datos innecesariamente.

Interpretación

Si BIOS detecta el disco, el problema puede ser de arranque o sistema.

04

4. Evaluar salud

Si el disco funciona, comprueba SMART/diagnóstico del fabricante.

Qué hacer

  1. Si el disco responde lo suficiente para cargar Windows, respalda tus archivos de inmediato antes de cualquier otro diagnóstico.
  2. Usa el software del fabricante (Samsung Magician, Crucial Storage Executive, WD Dashboard) o CrystalDiskInfo para revisar SMART.
  3. Presta atención a "Media Wearout Indicator"/"Percentage Used" y a errores de lectura/escritura no corregibles.
Punto de control

Si el disco funciona, comprueba SMART antes de asumir que está sano solo porque "todavía enciende": puede mostrar comportamiento errático mucho antes de fallar del todo.

Interpretación

Si el disco funciona, comprueba SMART/diagnóstico del fabricante.

Diagnóstico final

Resultado: si todas las pruebas externas son correctas y el fallo permanece, ya tienes una hipótesis más concreta. No cambies chips, puertos o placas por intuición: documenta síntomas y mediciones.

Fuentes y notas

Microsoft documenta Reparación de inicio en WinRE para problemas de arranque. No confundas una falla de Windows con un SSD que ni siquiera aparece en firmware.
