# NúcleoTech — Biblioteca de Reparaciones v6

## Estructura de Reparaciones
- **Consolas:** PlayStation 4, PlayStation 5 y Xbox.
- **PC / Laptop:** diagnóstico de arranque, RAM, SSD, temperatura, red y alimentación.
- **Celulares:** carga, batería, USB-C, pantalla, reinicios, almacenamiento y mantenimiento.
- **Mantenimiento:** rutinas preventivas.
- **MikroTik:** biblioteca independiente con RouterOS CLI, comandos de configuración y consultas de verificación.

## Navegación
`reparaciones.html` funciona como índice minimalista con filtros por categoría. La sección MikroTik está separada en `mikrotik.html`.

## MikroTik
Cada guía sigue el ciclo:
1. Consultar estado.
2. Aplicar una configuración concreta.
3. Volver a consultar.
4. Interpretar el resultado.
5. Documentar el cambio.

Los comandos usan ejemplos RouterOS v7 y deben adaptarse a la topología real (interfaces, subredes, listas WAN/LAN y versión instalada).

## AdSense
Los contenedores `adsense-slot` quedan preparados para insertar unidades después de configurar AdSense. No se incentivan clics ni se camuflan anuncios como contenido.

## Imágenes
Los diagramas de `imagenes/guias` y `imagenes/biblioteca` son gráficos originales de NúcleoTech. Las fotografías de terceros, cuando existan, deben conservar su atribución y licencia correspondiente.
