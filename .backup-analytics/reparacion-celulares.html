Celular que no carga: diagnóstico seguro paso a paso

Guía práctica: síntomas, comprobaciones, orden de diagnóstico y precauciones.

Guía técnica · NúcleoTech · 2026

Antes de empezar

El objetivo no es adivinar qué pieza está dañada. Primero se reproduce el síntoma, se hacen pruebas sencillas y se elimina cada posible causa. Si una prueba cambia el comportamiento, documenta el resultado y úsalo para el siguiente paso.

Procedimiento paso a paso

  1. Paso 1: Prueba un cargador y cable conocidos.
  2. Paso 2: Revisa visualmente el puerto con buena iluminación.
  3. Paso 3: Si hay suciedad superficial, limpia con el equipo apagado y sin forzar contactos.
  4. Paso 4: Observa si aparece el indicador de carga.
  5. Paso 5: Si carga intermitente, diferencia entre cable, puerto y batería.
  6. Paso 6: Si se calienta demasiado, huele extraño o la batería está hinchada, deja de cargarlo.

Precauciones

Nunca pinches, dobles ni calientes una batería de litio dañada.

Cómo documentar el diagnóstico

Anota modelo exacto, síntoma, pruebas realizadas y resultado de cada prueba. Si publicas el caso en Facebook, añade fotografías del equipo antes y después, pero elimina datos personales que aparezcan en pantalla.
