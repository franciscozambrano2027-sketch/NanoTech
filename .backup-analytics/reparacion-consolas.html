Cómo diagnosticar una consola antes de desmontarla

Guía práctica: síntomas, comprobaciones, orden de diagnóstico y precauciones.

Antes de empezar

El objetivo no es adivinar qué pieza está dañada. Primero se reproduce el síntoma, se hacen pruebas sencillas y se elimina cada posible causa. Si una prueba cambia el comportamiento, documenta el resultado y úsalo para el siguiente paso.

Procedimiento paso a paso

  1. Paso 1: Graba el síntoma: luz, pitido, mensaje, apagado o falta de imagen.
  2. Paso 2: Prueba otra toma y cable compatible.
  3. Paso 3: Conecta directamente al televisor y prueba otro HDMI.
  4. Paso 4: Si se apaga bajo carga, comprueba ventilación y temperatura.
  5. Paso 5: Si el sistema inicia, revisa almacenamiento y actualizaciones.
  6. Paso 6: Solo después considera desmontaje y mediciones.

Precauciones

Desconecta la consola antes de abrirla. No uses líquidos dentro del equipo.

Cómo documentar el diagnóstico

Anota modelo exacto, síntoma, pruebas realizadas y resultado de cada prueba. Si publicas el caso en Facebook, añade fotografías del equipo antes y después, pero elimina datos personales que aparezcan en pantalla.
